# Code of conduct

This project adopts [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
by reference. The summary below describes how it applies here.

Participation should be welcoming to everyone. Be considerate, accept constructive feedback,
and discuss ideas respectfully. Harassment, discrimination, sexual advances, personal attacks,
and disclosure of private information are prohibited. These expectations cover project spaces
and public activity representing the project.

Maintainers review reports fairly and protect reporters' privacy. They may moderate contributions
and apply a correction, warning, temporary ban, or permanent ban according to the incident's severity
and whether it is repeated. Reports about repository activity can be sent privately through the
repository's GitHub reporting tools, addressed to the maintainer. Never post a victim's private details publicly.

The linked covenant is the complete policy, including its enforcement guidelines and attribution.
